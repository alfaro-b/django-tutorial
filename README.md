# Tutoriel Django

Exercices réalisés dans le cadre de la formation Concepteur Développeur d'Applications (CDA).

## Technologies utilisées

- Python 3.14
- Django 5.2.18
- SQLite
- DB Browser for SQLite

## Contenu

Ce dépôt contient :
- Le projet Django `mysite` et son application `polls`.
- Les exercices complémentaires du tutoriel Django.
- Les comptes-rendus des manipulations au format Markdown.

## Organisation du dépôt

- `mysite/` : projet Django.
- `reports/` : comptes-rendus des exercices.
